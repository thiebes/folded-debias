# Datasets -- zhang-qd-control

Published-figure data digitized from Zhang et al. (2022), "Ultrafast exciton
transport at early times in quantum dot solids."

## In-repo (committed)

The extracted `Figure *.csv` files in this folder are small and committed
directly (the data the panel actually uses).

## Source binary (local only, not committed)

`zhang_Manuscript_data.opju` -- the raw Origin project the CSVs were extracted
from. It is a ~1.2 MB binary and is gitignored (`*.opju`); it is kept locally in
this folder for provenance but never committed. If a clean machine needs it,
re-extract the CSVs from the published paper's source data or copy the `.opju`
out of band.

## Note

This is published-paper data, not collaborator pshare data; there is no pshare
pointer.
