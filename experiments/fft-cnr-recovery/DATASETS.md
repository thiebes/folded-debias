# Datasets -- fft-cnr-recovery

This set derives its figure from one array in the sibling fft-cnr paper repo. The
array is synthetic (generated by the fft-cnr validation suite), not collaborator
data.

| Item | Location | What it is |
| ------- | ------- | ------- |
| Source array | `../fft-cnr-paper/validation/results/case1_gaussian_1d.npz` (sibling repo; ~2.3 MB) | 1000 fft-cnr estimates per (window size N, true CNR) for the Gaussian 1-D validation case (case 1). |
| Committed summary | `fft_cnr_recovery_summary.npz` (this folder) | Per-(N, CNR) median and 25/75, 5/95 percentiles reduced from the source; ~120 floats. The figure plots from this. |

The build script reads the source only when the committed summary is missing, then
writes the summary. The repos are expected side by side under `repos/`; if the
sibling path differs, adjust `SOURCE` in `build_fft_cnr_recovery_figure.py`.
